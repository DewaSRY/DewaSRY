## 🌸 About Me

- 💼 Full-stack developer at **[Labamu](https://labamu.co)**, building with **Golang** + **Next.js**
- 🛠️ Led the migration of 20+ feature modules from client-side to server-side rendering, and designed the platform's unified auth layer + Server Action contract
- 📡 Built a real-time in-app notification system from scratch using Server-Sent Events (no WebSockets needed!)
- 📊 Built an entity-agnostic bulk-upload engine with AI-assisted column mapping, letting users onboard thousands of records in one go
- ⚡ Fun fact: once took a page load from **5 minutes → 1 second** (300x!) by offloading heavy work to a Rust service
- 🎓 Currently sharpening my CS fundamentals — data structures, algorithms & software engineering — at Universitas Siber Asia
- 🎯 Looking to grow as a backend/full-stack engineer on scalable distributed systems
- 💬 Ask me about Go, Next.js, SSE, or migrating messy legacy code into something clean
